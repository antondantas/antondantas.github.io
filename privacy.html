Política de privacidade

dantashermes · vigente desde 05/10/2026

1. Quem usa e quem responde

dantashermes é uma ferramenta pessoal de uso individual. O único usuário é o seu autor, Anton Dantas, que também é o responsável por ela. Contato: antondantas@gmail.com.

2. Dados do Google acessados

Com a autorização do próprio dono, pelo escopo https://www.googleapis.com/auth/gmail.readonly, a ferramenta lê da conta Gmail do dono: a lista de e-mails não lidos recentes da caixa de entrada e, de cada um, remetente, assunto, data e corpo em texto. Anexos nunca são baixados. Nenhum outro dado do Google é acessado.

3. Como os dados são usados

Os dados lidos servem só para classificar cada e-mail em uma categoria fixa e, nos e-mails que pedem atenção, escrever uma frase curta sobre o assunto. A classificação é feita por um modelo de linguagem executado localmente, no computador do dono. Os dados não são usados para publicidade, perfilamento, venda, nem para treinar ou aprimorar modelos de inteligência artificial.

4. Armazenamento

O conteúdo dos e-mails (remetente, assunto, corpo e resumo) não é gravado em disco nem em registro. A ferramenta guarda no computador do dono apenas uma marca de "já visto" de cada e-mail entregue (o hash SHA-256 do identificador da mensagem e a categoria atribuída) e contagens de execução. As credenciais de acesso ficam no computador do dono, fora de qualquer repositório público.

5. Compartilhamento

Os dados do Google não são vendidos nem compartilhados com terceiros. A única saída é o aviso entregue ao próprio dono, no chat pessoal dele no Telegram (contagens por categoria e, para os e-mails que pedem atenção, remetente, assunto e a frase curta). O Telegram atua apenas como meio de entrega ao próprio dono.

6. Uso limitado (Limited Use)

dantashermes's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

7. Revogação e exclusão

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions. Revogado o acesso, a ferramenta deixa de ler o Gmail. As marcas de "já visto" ficam só no computador do dono e podem ser apagadas por ele a qualquer momento.

8. Alterações

Mudanças nesta política são publicadas nesta página, com a nova data de vigência.

In English

dantashermes is a single-user personal tool. With its owner's consent and the read-only scope gmail.readonly, it reads sender, subject, date and plain-text body of recent unread inbox messages of the owner's own Gmail account, never attachments. Messages are classified by a language model running locally on the owner's computer; the only output is a short summary sent to the owner's own Telegram chat. Message content is not stored, logged, sold, shared or used to train AI models; only a SHA-256 hash of each delivered message id and its category are kept locally. Access can be revoked at https://myaccount.google.com/permissions. Contact: antondantas@gmail.com.
